# Design Direction

Design constraints:

- typography: no bold anywhere — hierarchy by size and space alone
- layout: one element deliberately breaks the grid
- color: no pure white and no pure black anywhere

Concept: A warm, precise clinical intake that feels like a carefully registered case sheet rather
than a generic health-tech landing page. The signate metaphor appears as a single registration mark
that crosses the content grid and identifies the current stage.

## Contract

Fonts:     "Avenir Next" for interface copy; "Iowan Old Style" for display moments; named fallbacks only
Palette:   parchment #F2EFE9 background; paper #FBF8F2 surfaces; ink #1D2A2A text; teal #176B66 actions; clay #C86448 cautions; line #C9C2B8 borders
Shape:     square cards and controls with 2px corners; pill shapes prohibited; 1px borders throughout
Space:     calm 8px rhythm with narrow text measures and asymmetrical vertical gaps
Signature: a clay registration mark and stage numeral deliberately crossing the main card boundary
