# Request: anonymized cases to validate the AI quote tool

**Purpose.** Before we put the AI pre-quote tool in front of patients, we validate it against
real cases where the treating dentist's plan is known. This is the only honest way to know it's
accurate enough — and it protects the clinic's reputation.

**What we're asking for: ~15–20 past cases.** For each:

1. **Anonymized panoramic x-ray** (JPEG/PNG). Remove the patient's name, date of birth, and any
   on-image identifiers. No other patient documents.
2. **The treatment plan you actually proposed** — in plain terms:
   - which teeth/areas were treated,
   - number of **new** implants (and note any implants already present),
   - crowns / bridges / veneers / dentures,
   - any extractions.
3. **The price you quoted** for that plan (so we can check the € figure, not just the treatments).
4. **Patient's original message/request** if available, and the language (IT / EN / …).

**Consent & privacy.** Use only cases where you have a lawful basis to share anonymized clinical
images for quality/validation under GDPR and the national law applicable to the deployment. Images must be de-identified
before sending. We store them encrypted, use them solely for this validation, and delete on request.
No patient-identifying data is needed or wanted.

**Spread we'd love.** A mix: single implant, a few implants, full-arch (All-on-4/6), crowns,
veneers/"smile", and a couple with existing restorations already in the mouth.

**Why it helps you.** You get a tool that gives prospective patients an instant, *indicative*
ballpark — every output is explicitly non-diagnostic and routed to you for confirmation — which
turns more enquiries into booked consultations without adding front-desk work.
